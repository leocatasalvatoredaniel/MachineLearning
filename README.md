# Machine Learning (ML4N) – appunti di studio

- `docs/index.html`: ripasso di Python (lezione 1) e NumPy (lezione 2), spiegato passo per passo con esempi ed esercizi di autoverifica.
- `numpy/02_numpy_spiegato.py`: gli stessi esempi di NumPy come celle eseguibili in VS Code.

## Come aprire il sito

- **Dal PC**: dopo `git pull`, apri `docs/index.html` con doppio clic (si apre nel browser).
- **Online**: con GitHub Pages attivo (Settings → Pages → branch, cartella `/docs`).
